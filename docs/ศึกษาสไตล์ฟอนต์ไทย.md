# ศึกษาสไตล์ฟอนต์ไทย → นำแนวคิดมาใช้กับฟอนต์ลาว

> ภาษาไทยมีฟอนต์เป็นพันแบบ ส่วนภาษาลาวมีไม่กี่แบบ อักษรสองภาษามีโครงสร้างคล้ายกัน (หัว/ห่วง, สระบนล่าง, วรรณยุกต์ซ้อน)
> เอกสารนี้ศึกษา**แนวคิดของสไตล์**เท่านั้น
> **ไม่คัดลอกเส้นหรือไฟล์ฟอนต์ไทยใด ๆ** ทุกตัวสร้างจากเส้นของ Noto Sans Lao (OFL) ด้วยการแปลงทางคณิตศาสตร์

## กลุ่มสไตล์ที่พบบ่อยในฟอนต์ไทย และสิ่งที่นำมาใช้
| กลุ่มสไตล์ไทย | ลักษณะเด่น | ใช้กับอะไร | นำมาทำเป็นฟอนต์ลาว |
|---|---|---|---|
| ไทยมีหัวแบบดั้งเดิม | หัวกลม อ่านง่ายสุด | หนังสือ ข่าว | ต้นแบบ Looped (มีอยู่แล้ว) |
| ไทยไม่มีหัวแบบโมเดิร์น | เส้นเรียบ ดูสากล | แบรนด์ โฆษณา | ນຸ່ມ (v1) |
| ตัวกลมมน | ปลายเส้นมน ดูเป็นมิตร | เด็ก อาหาร ไลฟ์สไตล์ | ມົນ (v1) |
| ตัวแคบสูง (Condensed) | แคบ หนา ใส่คำได้เยอะ | พาดหัว ปก thumbnail | **ແຄບ (v2)** แกนความกว้างของ Noto |
| ตัวเหลี่ยม/เทค | โค้งกลายเป็นมุมตัด ดูล้ำ | เกม เทคโนโลยี กีฬา | **ຫຼ່ຽມ (v2)** แปลงโค้งเป็นเส้นตัดมุม |
| ตัวเอียงไดนามิก | เอียงไปข้างหน้า ดูเร็ว มีพลัง | กีฬา โปรโมชัน ซับเร้าใจ | **ອຽງ (v2)** เอียงเส้น + ย้ายจุดยึดสระตาม |
| ตัวกลวง/ตัวขอบ | มีแต่เส้นขอบ | ป้าย หัวข้อใหญ่ | ຂອບ (v1) |
| ตัวลายมือ/ตัวการ์ตูน | เส้นไม่สม่ำเสมอ ตัวเด้งขึ้นลง | ซับตลก คอนเทนต์สนุก | ทำเป็น**ท็อปปิ้งตัวเด้ง**ตอนแสดงผล (ตัวอักษรจริงไม่ถูกแตะ) |

## บทเรียนจากฟอนต์ไทยที่ใช้กับซับวิดีโอ
1. **ซับบนวิดีโอนิยมตัวหนา + ขอบดำหนา** เพราะอ่านออกบนทุกพื้นหลัง
2. **ตัวไม่มีหัวดูทันสมัย แต่ตัวมีหัวอ่านง่ายกว่า** โดยเฉพาะผู้อ่านสูงอายุ จึงควรมีให้เลือกทั้งสองแบบ
3. **สีที่เห็นบ่อย**: ขาว+ขอบดำ, เหลือง+ขอบดำ, ขาวบนกล่องสี และคำสำคัญเปลี่ยนสี
4. **สไตล์ไม่ควรล็อก**: ครีเอเตอร์ชอบปรับสีและขอบเอง จึงทำเป็น "ท็อปปิ้ง" ที่ซ้อนกันได้
