## หน้าแต่งซับ (`preview.html`) — ฟอนต์ + สี + ท็อปปิ้ง
- **สี**: เลือกได้ทั้งสีเดียวและไล่สี 2 สี
- **ท็อปปิ้งซ้อนกันได้ไม่จำกัด** สลับลำดับได้ (↑↓) และลบได้ (✕) มีทั้งหมด 7 แบบ:
  - ขอบ (ใส่หลายชั้นได้ เช่น ขอบสองชั้น)
  - เงา
  - เรืองแสง
  - กล่อง (ทีละคำ / ทั้งบรรทัด)
  - แถบปากกาเน้น
  - เน้นคำ (ใส่ `*คำ*` ในข้อความ)
  - อีโมจิ
- **แอนิเมชัน 6 แบบ**: ไม่มี / คาราโอเกะ / เด้งทีละคำ / พิมพ์ทีละคำ / ตัวเด้งดึ๋ง / สั่น
- **สไตล์เริ่มต้น 7 แบบ** กดแล้วแก้ต่อได้ ไม่ล็อก
- **บันทึก/แชร์สไตล์เป็น JSON** (คัดลอก/วาง) ซึ่งเป็นรูปแบบเดียวกับที่จะใช้ตอนส่งออกวิดีโอในอนาคต

**ลิขสิทธิ์:** ดัดแปลงจาก Noto Sans Lao ซึ่งใช้สัญญา SIL OFL 1.1 (ดู `v1/OFL.txt`)
- ใส่ในแอปและขายแอปได้
- ห้ามขายตัวฟอนต์เดี่ยว ๆ
- ฟอนต์ที่ดัดแปลงต้องใช้ OFL ต่อ จึง**ไม่ได้เป็นของเราคนเดียว**
- ถ้าอยากได้ฟอนต์ที่เป็นของเราคนเดียว ต้องใช้โครงตัวอักษรที่เราออกแบบเอง

## สร้าง / ตรวจ / ดู
```
.venv-fonts\Scripts\python.exe scripts\fonts\build_fonts.py --version v2
.venv-fonts\Scripts\python.exe -u scripts\fonts\qa_fonts.py --version v2
```
- แก้สไตล์ได้ที่ `STYLES` ใน `scripts/fonts/build_fonts.py`
- ทุกเวอร์ชันมีโฟลเดอร์ของตัวเอง ห้ามเขียนทับ
- รายงานผลตรวจอยู่ที่ `fonts/<version>/qa/report.md` พร้อมรูปเทียบกับต้นแบบ
- หน้าพรีวิว: ใช้ preview server ชื่อ `fonts` (พอร์ต 8790) แล้วเปิด `preview.html`

## ตรวจอะไรบ้าง (v1 ผ่านครบทั้ง 3 ฟอนต์)
ทดสอบ 2,052 พยางค์ (ทุกพยัญชนะ × สระบน/ล่าง × วรรณยุกต์) และ 1,207 บรรทัดซับจริงจาก `data/subs`
1. ครบตัวอักษร
2. จัดวางเหมือนต้นแบบ (HarfBuzz)
3. รูปทรงไม่พัง: จำนวนชิ้นเท่าเดิม และรู/ห่วงไม่ถูกถม
4. แยกตัวอักษรออก: ບ/ປ, ຜ/ຝ, ດ/ຕ ฯลฯ
5. สระ-วรรณยุกต์ไม่ชนกัน
6. ไม่ล้นขอบบน/ล่าง

## บทเรียน
- การมนมุมแบบตรง ๆ (หดแล้วขยาย) ทำให้**ห่วงเล็กบนหัวตัวอักษรลาวหายไป** เช่น ຄ กลายเป็นคล้าย ກ
  → แก้โดยเอาส่วนบางที่หายไปกลับคืนมา และมีตัวกันที่ลดรัศมีลงเองถ้าจำนวนชิ้นหรือรูเปลี่ยน
- การมนมุมเว้าทำให้จุดของ ຶ ື ติดกับตัวสระได้ ตัวกันชุดเดียวกันจับได้
